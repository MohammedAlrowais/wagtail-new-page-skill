# new-page

An AI agent skill that builds a new Wagtail page type (a detail page plus an
optional listing page) in any Django + Wagtail project, and checks the
result against a performance and quality checklist.

The instructions are in [`SKILL.md`](SKILL.md). Any AI coding agent and any
model that can read your files and run commands can follow them.

See the [main README](../README.md) for what it does, how to install it and
how to use it.
